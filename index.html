免费 Apple ID 也能装；签名 7 天到期需要在手机上重签一次。选一种方式把 App 装到这台设备。

方式一：SideStore 一键安装免费 · 推荐

点下面的按钮，系统会唤起 SideStore，用它自己的签名流程安装本 App。

用 SideStore 安装 用 AltStore 安装
没装 SideStore？展开看首次配置（电脑只做一次）
  1. 电脑装 Sideloadly，从 SideStore Releases 下载 SideStore.ipa，连线装到手机；
  2. iPhone 连电脑 → 点「信任此电脑」→ 运行 jitterbugpair.exe，得到 *.mobiledevicepairing 配对文件；
  3. 把这个配对文件发到手机，在 SideStore 里 Settings → Choose Pairing File 导入，并登录同一 Apple ID；
  4. iOS 17.4 以上还需要装 SideStore 给的本地 VPN 配置（WireGuard/StosVPN），否则会报 no Wi-Fi or VPN；
  5. 回到本页点「用 SideStore 安装」即可。
