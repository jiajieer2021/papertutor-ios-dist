错题喵 iOS 安装

选一种方式把 App 装到这台 iPhone / iPad。免费 Apple ID 也能装，但签名 7 天到期需要重签。

方式一：SideStore / AltStore 一键安装免费

点下面的按钮，系统会唤起 SideStore（或 AltStore）用它自己的签名流程安装本 App。

用 SideStore 安装 用 AltStore 安装

没装过 SideStore / AltStore？先按方式三准备（只需要在电脑上做一次）。

方式二：OTA 直装需付费开发者账号

只有用 Ad Hoc / Enterprise 证书签名、并把本机 UDID 加进 provisioning profile 后可用。

通过 itms-services 安装

若提示「无法连接」或「无法安装」，说明当前 PaperTutor.ipa 仍是未签名包 —— 请用方式一。

方式三：电脑下载 + Sideloadly

下载 PaperTutor-unsigned.ipa
  1. Windows 装 Sideloadly，iPhone 用线连电脑；
  2. Sideloadly 选刚下载的 ipa，填 Apple ID，点 Start；
  3. 手机「设置 → 通用 → VPN 与设备管理」信任证书。

包信息：com.papertutor.miao · arm64 真机包 · 由 GitHub Actions 的 macOS 虚拟机编译。
未签名包无法直接安装，必须用你自己的 Apple ID 重签，这是 iOS 的机制。
